## 🎯 О проекте

**Nexgram** — это не просто мессенджер. Это полноценная платформа для общения, созданная с нуля на Flask и Socket.IO. Проект объединяет лучшие идеи популярных мессенджеров: истории как в Instagram, каналы как в Telegram, видеозвонки как в WhatsApp, и всё это в одном веб-приложении!

> **💡 Рекомендация от автора:** Для наилучшего отображения интерфейса используйте масштаб браузера **90%** (Ctrl/Cmd + "-" дважды). Это обеспечит идеальное позиционирование всех элементов интерфейса!

## ✨ Ключевые возможности
<div align="center">
### 🎨 Уникальный дизайн
- Стильный тёмный интерфейс с акцентным градиентом
- Плавные анимации и переходы
- Настраиваемые темы оформления
- Кастомные баннеры профиля с градиентами и изображениями

### 💬 Умные чаты
- Мгновенная доставка сообщений через WebSocket
- Индикатор набора текста
- Закрепление важных чатов
- Счётчик непрочитанных сообщений
- Поиск по сообщениям с подсветкой результатов

### 🎭 Реакции и эмоции
- **6 быстрых реакций** на сообщения (👍❤️😂😮😢😡)
- **15+ полных реакций** в расширенной панели
- Анимированные лайки с летящими сердечками
- Реакции на истории (❤️🔥👎👍)

### 📸 Истории 2.0
- Загрузка фото и видео с автовоспроизведением
- Таймер с прогресс-баром
- Статистика просмотров, лайков и реакций
- Ответы на истории прямо в чат
- Автоматическое удаление через 24 часа

### 👥 Группы и каналы
- Создание публичных и приватных групп
- Система прав (владелец, админ, участник)
- Пригласительные ссылки
- Каналы с подписками
- Администраторы каналов с разными правами

### 🎵 Мультимедиа
- Встроенный музыкальный плеер
- Плейлисты с возможностью загрузки MP3
- Отправка фото, видео, аудио и документов
- Предпросмотр файлов перед отправкой
- Просмотр изображений в полном размере

### 📹 Видеозвонки
- Звонки один на один и групповые
- WebRTC технология (peer-to-peer)
- Поддержка аудио и видео
- Экран блокировки на время звонка

### 🔐 Безопасность
- Блокировка нежелательных пользователей
- Гибкие настройки приватности
- Просмотр и завершение активных сессий
- Удаление аккаунта с подтверждением

### 🎨 Кастомизация
- 4 предустановленных градиента для баннера
- 8 цветов для персонализации
- Загрузка своего изображения на баннер
- Настройка цвета сообщений
- Регулировка размера шрифта и радиуса пузырьков
- Установка обоев для чатов

## 📦 Быстрый старт

### Предварительные требования
- Python 3.8 или новее
- pip (менеджер пакетов Python)

### Установка и запуск

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/yourusername/nexgram.git
cd nexgram

# 2. Установите зависимости
pip install flask flask-socketio pillow

# 3. Запустите сервер
python main.py

# 4. Откройте в браузере
# http://localhost:5000
